# Experiment configs

One YAML per experiment, added as each experiment is built (Phases 12–17). Each file names a base
model config plus a list of runs (name + dotted overrides) and the figures/tables to regenerate.
See `docs/project_specification.md` §9 for the schema and an example.

The matching protocol write-up for each experiment lives in `experiments/NN_name/README.md`.
