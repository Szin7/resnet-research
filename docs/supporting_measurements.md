# Supporting figures and compute diagnostics

The original four figures were generated by `scripts/run_experiment.py` using all eight completed single-seed CIFAR-10 runs and archived in Google Drive. The following published, measurement-derived tables accompany the main [results](results.md):

- [Eight-model T4 benchmark](../results/tables/benchmark_all8.csv): parameter count, per-image MACs, measured latency and synthetic-step peak memory for batch sizes 1 and 32.
- [Five-epoch gradient probe summary](../results/tables/gradient_norm_summary.csv): min/max/median/mean layer-weight gradient norms at epochs 0, 1, and 5.

These benchmarks do not depend on trained checkpoint weights: they instantiate the model configurations and use synthetic inputs. Their latency measurements should be treated as environment-specific, not deterministic hardware speed rankings. The gradient probe starts fresh models and must **not** be described as a probe of the finished 80-epoch networks.
