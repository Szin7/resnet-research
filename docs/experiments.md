# Experiment guide

The source code and experiment configurations are prepared, but the results below must be generated by actual runs. The question for every comparison is whether the training observations support the stated hypothesis.

## Research procedure

1. Use the fixed CIFAR-10 split and record the complete model and training configuration.
2. Run the plain and residual networks under the same schedule and seed.
3. Compare **training loss and training error first**. The central degradation claim concerns optimization, not simply worse validation accuracy.
4. Evaluate final and best-validation checkpoints on the held-out test set after training. Do not use the test set to tune hyperparameters.
5. Repeat the headline comparison with additional seeds and report variation.
6. Explain surprising outcomes and note deviations from the paper rather than changing the recorded hypothesis.

## Available experiment configurations

- `01_depth/experiment.yaml` — plain and residual depth sweep, 20 to 56 layers
- `02_plain_vs_residual/experiment.yaml` — matched-depth shortcut comparison
- `03_residual_ablation/experiment.yaml` — residual connection present vs absent
- `04_identity_vs_projection/experiment.yaml` — shortcut options A/B/C
- `06_ablation_grid/experiment.yaml` — depth, residual flag, BatchNorm
- `07_batchnorm/experiment.yaml` — BatchNorm settings; the LR difference is a documented confound
- `08_optimization/experiment.yaml` — step/cosine/constant schedules and momentum
- `09_augmentation/experiment.yaml` — standard augmentation vs no augmentation

Gradient flow is a separate short instrumented run using `scripts/analyze_gradients.py`; benchmarking uses `scripts/benchmark.py`.

## Commands

```bash
python scripts/run_experiment.py --experiment experiments/01_depth/experiment.yaml --dry-run
python scripts/run_experiment.py --experiment experiments/01_depth/experiment.yaml --device cuda
python scripts/analyze_gradients.py --models plain_56 resnet_56 --epochs 5 --device cuda
python scripts/benchmark.py --models plain_20 resnet_20 plain_56 resnet_56 --device cuda
```

All reported metrics must be sourced from `results/runs/`, not from expected values or published paper numbers. The 80-epoch standard schedule and reflected padding are deviations from the original paper.
